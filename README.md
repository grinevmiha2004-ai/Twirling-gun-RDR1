# TwirlingGun 0.3 — RDR1 PC / ScriptHookRDR

Двойное короткое нажатие назначенной кнопки кобуры запускает действие вращения револьвера. 0.3 использует найденную в присланном Rampage Trainer последовательность: набор `holster_spin`, дерево `custom/holster_spin` и `TASK_ACTION_PERFORM` внутри последовательности задач.

**Статус: сборка Windows x64 и автоматические проверки прошли. В версии 0.2 пользователь подтвердил правильную анимацию, но револьвер исчезал из руки. Новая подготовка оружия в 0.3 ещё не проверена в реальной игре.** Сборка 0.1 отозвана после отсутствия вращения и потери управления. Не используйте её, включая старые копии из Git-истории.

## Изменение 0.3

Запуск ждёт отпускания второй кнопки и ещё 150 мс для обработки штатного ввода. После назначения набора анимаций мод всегда возвращает исходный револьвер в руку. Перед вращением требуется стабильное подтверждение оружия в течение 100 мс; при повторном исчезновении подготовка повторяется с общим пределом 1,5 секунды. Во время вращения вызовов доставания оружия нет, чтобы не мешать естественному убиранию.

Это исправление порядка подготовки, а не перехват первого нажатия: короткое обычное убирание перед вращением пока может оставаться видимым. Проверка native-состояния не гарантирует видимость модели; новая сборка требует проверки на ПК пользователя.

## Установка обновления

1. Закройте игру полностью. Если управление уже пропало, одного изменения файлов недостаточно: нужен перезапуск игры.
2. Замените старые `TwirlingGun.asi` и `TwirlingGun.ini` файлами из архива 0.3 рядом с `RDR.exe`. Старый `.asi` не оставляйте под другим именем в папке игры.
3. Нужны установленные `ScriptHookRDR.dll` и `dinput8.dll`. Если Rampage уже работает с ScriptHookRDR, повторно устанавливать загрузчик не требуется. RedHook для этого мода не нужен.
4. Загрузите сохранение, встаньте пешком вне укрытия, достаньте револьвер и дважды коротко нажмите кнопку кобуры с интервалом до 300 мс. Стандартная клавиша клавиатуры — Tab.
5. Если действие зависло, нажмите **F10**. Клавиша отменяет только активную попытку этого мода, а не произвольное состояние игры. Если управление не восстановилось, удалите `.asi` и перезапустите игру; пришлите `TwirlingGun.log`.

Поддерживаются Cattleman, Schofield, Double-action и LeMat. Переназначение кнопки в игре учитывается через `@RADIAL_MENU.SHOW_HIDE`. Одиночное нажатие и удержание не перехватываются. Первое нажатие может начать обычное убирание: при необходимости мод достаёт исходный револьвер перед запуском действия. Плавность перехода и работа геймпада требуют игровой проверки.

Мод не вызывает `TASK_PLAY_ANIM`, не подбирает имя клипа и не выполняет отдельное принудительное убирание после вращения: нужный переход должен выполнить действие `holster_spin`. Назначение набора анимаций теперь использует третий аргумент `1`, как Rampage; в 0.1 был `0`. Само назначение набора не удалено — оно является частью найденной схемы, теперь с ограничением времени и очисткой.

## Защита от зависания

Загрузка ресурсов ограничена 3 секундами, ожидание устойчивого состояния револьвера — 1,5 секундами, выполнение действия — 8 секундами. На завершении сбрасываются назначенный модом набор и включённый им режим готовности. При принудительной отмене дополнительно очищается собственная последовательность и сбрасывается дерево действий. При смерти/смене персонажа недействительный actor не используется.

Проверка `IS_PLAYER_CONTROLLABLE` выполняется только перед началом, поскольку само scripted-действие может временно менять этот признак. Нормальный выход не зависит от проверки имени анимации: используется `GET_NTH_TASK_STATUS`, как Rampage. Статус задачи не доказывает видимого вращения, поэтому журнал не объявляет анимацию визуально успешной.

Ограничения: восстановление нестандартных наборов и режима готовности, назначенных другими модами, не поддерживается. Взаимодействия с миссиями и другими модами, аварийная выгрузка плагина и визуальный результат проверяются на реальной игре. Перед тестом не запускайте параллельно `Twirl Gun` через меню Rampage.

## Удаление

Удалите `TwirlingGun.asi` и `TwirlingGun.ini`, перезапустите игру. Общий загрузчик оставьте для других ASI-модов.

## Сборка

Linux в подготовленной среде: `bash build.sh`. При отсутствии компилятора: `bash scripts/setup-cloud.sh`. Инструменты устанавливаются в `/workspace/tools`, исходники игры не меняются. Можно задать `CXX_HOST` и `CXX_WIN`.

Windows: `build-windows.cmd` в x64 Native Tools Command Prompt Visual Studio 2022; этот путь здесь не выполнялся. Выдаваемый бинарник собран MinGW GCC 14.2 и зависит только от KERNEL32.dll, USER32.dll и msvcrt.dll.

В архиве нет чужих hook DLL, Rampage.asi, RDR.exe или ресурсов игры. Подробности исследования: [docs/rampage-recipe.md](docs/rampage-recipe.md); проверки: [docs/validation.md](docs/validation.md).
