# TwirlingGun для RDR1 PC

Экспериментальный ASI-мод для ScriptHookRDR 1.5.1: двойное нажатие назначенной в игре кнопки колеса оружия / кобуры запрашивает вращение револьвера, после завершения анимации — убирание в кобуру.

**Статус: собран для Windows x64, логика нажатий проверена тестами. В игре не проверен.** Название ресурса `holster_spin` найдено в справочнике файлов RDR1; внутреннее имя клипа `holster_spin` — пока предположение. Пункт Rampage «Twirl Gun» сам по себе не подтверждает это имя. Поэтому эта сборка не является подтверждённо рабочим релизом.

## Установка

1. Закройте игру. Откройте папку, в которой находится `RDR.exe`.
2. Если ScriptHookRDR ещё не установлен, скопируйте туда `ScriptHookRDR.dll` и `dinput8.dll` из присланного вами архива ScriptHookRDR 1.5.1. Если они уже есть, сначала сохраните их резервные копии; не заменяйте другой загрузчик вслепую.
3. Скопируйте рядом `TwirlingGun.asi` и `TwirlingGun.ini` из папки `dist`.
4. Загрузите сохранение, встаньте пешком и достаньте Cattleman, Schofield, Double-action или LeMat.
5. Дважды коротко нажмите кнопку кобуры с интервалом до 300 мс. По умолчанию используется действие `@RADIAL_MENU.SHOW_HIDE`, поэтому переназначение кнопки в игре учитывается. На стандартной клавиатуре это Tab.

RedHook для этого ASI не нужен. Архив мода не содержит чужие хуки или файлы игры. Файлы `.was`, которые вы прислали, устанавливать не нужно: они относятся к вращению ключей, а мод запрашивает встроенный ресурс игры.

Одиночное нажатие и удержание не перехватываются. Игра по-прежнему сама обрабатывает их. При двойном нажатии первое нажатие может уже начать обычное убирание; мод восстанавливает исходный револьвер перед запросом анимации. Плавность этого перехода требует проверки в игре.

## Если вращение не сработало

После попытки закройте игру и пришлите `TwirlingGun.log` из папки игры. В журнале различаются ошибки загрузки набора, применения набора и начала клипа. Сообщение `Game confirms animation is playing` означает, что native проверки воспроизведения вернул положительный результат; внешний вид движения всё равно проверяется визуально.

Если лог не появился, проверьте `ScriptHookRDR.log`: загрузился ли сам ASI. Совместимость присланного ScriptHook с вашей версией EXE нельзя подтвердить без запуска полной игры.

Если набор загрузился, но клип не запустился, нужны внутреннее имя/путь анимации из Rampage или извлечённые `holster_spin.was` и `holster_spin.wat`. Их можно исследовать без подмены игровых архивов. Параметры `Set` и `Clip` в INI позволяют уточнить имя без пересборки.

Мод отменяет запрос при паузе, смерти, смене персонажа, посадке верхом, падении, перезарядке, стрельбе, прицеливании, нахождении в укрытии или воде. Смена оружия во время самой анимации и взаимодействие с другими модами требуют игровой проверки. При отмене мод возвращает стандартный набор анимаций; нестандартные наборы, назначенные другими модами, он не сохраняет.

## Удаление

Удалите только `TwirlingGun.asi`, `TwirlingGun.ini` и `TwirlingGun.log`. Файлы общего загрузчика оставьте, если они нужны другим модам.

## Сборка

Linux: `bash scripts/setup-cloud.sh`, затем `bash build.sh`. Установка инструментов происходит вне checkout, в `/workspace/tools`. Можно задать `CXX_WIN` и `CXX_HOST` для своих компиляторов.

Windows: запустите `build-windows.cmd` из x64 Native Tools Command Prompt Visual Studio 2022. Этот путь сборки здесь не проверен; приложенный бинарник собран MinGW GCC 14.2.

Результат: `dist/TwirlingGun.asi`. Прямое обращение к ScriptHook идёт через его опубликованные экспорты; SDK и импортная библиотека для пересборки не нужны.

Подробности исследования и проверки: [docs/validation.md](docs/validation.md).
